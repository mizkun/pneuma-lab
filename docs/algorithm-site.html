心を計算し、
行動は選ばない。

Pneuma（プネウマ）は、AIキャラクターに「いまこの瞬間の内面」を持たせる仕組みです。性格・感情・人間関係を発話のたびに計算し直し、日本語の「心の中」として本人だけに手渡す。何をするかは、AIが自分で決めます。

1. 観測
これまでの出来事（発言・裏切り・賛成）を読む
2. 計算
性格・感情・関係の数値を更新
3. 翻訳
数値を日本語の「内面」にして本人だけに渡す
4. 選択
AIが行動と言葉を選ぶ。ここだけは計算しない
5. 記録
選択は出来事になり、次の計算の入力になる
↺ 発言のたびに、このループが回る

このページでは、クリーム色は常に「本人だけが受け取る内面」を意味します。

計算している、心の4つの層

性格変わらない土台。ビッグファイブ5因子と価値観10種。数値は不変だが、進行中の目標が一時的に性格を押し上げる。
感情揺れて、戻る。快−不快・覚醒・主導感の3軸。出来事で跳ね、時間とともにその人の平常へ戻る。神経症傾向が強い人ほど、嫌な出来事で大きく揺れる。
表出場で変わる顔。土台の性格に、場の圧力×「人の目を気にする度合い」と感情の影響を足した、いま表に出る性格。
関係向きのある温度。相手ごとの「親しみ」と「緊張」。賛成されれば温まり、裏切られれば張り詰める。私→あなた と あなた→私 は別の値。

計算はすべて乱数を使わない決定論。同じ出来事の列からは必ず同じ心理状態が導かれ、あとから完全に追跡できる。

出来事を起こすと、心が動く

実際のエンジンの簡易移植です。キャラクターを選び、出来事のボタンを押すと、数値が動き、閾値を越えた瞬間に「内面」の文章が変わります。

快−不快
覚醒
主導感
相手への緊張
いまのあなたの内面 — 本人だけが受け取る

同じ「裏切られる」でも、神経症傾向の高い凛は朱里より深く沈みます。性格が、感情の動き方そのものを変えます。

内面は、プロンプトの最後の一層になる

キャラクターへの入力は3層。実験ではこの層を出し分けて、素のAI・固定キャラ設定・Pneumaを比較しました。

層1 — 客観情報（全条件で共通）

状況の説明、これまでの会話、いま選べる行動、出力形式。主観は入らない。

層2 — 人物像（固定テキスト）

「場を明るくして人を前へ出したい。数字や成果がないと自分に価値がないように感じる」——変わらないアイデンティティ。

層3 — いまの内面（毎ターン計算）

「胸の奥が重い。朱里との間には張り詰めたものを感じている。反対があっても言い出しにくい」——上の実験機で見た、あの文章。

素のAI = 層1のみ　／　固定キャラ設定 = 層1+2　／　Pneuma = 層1+2+3

なぜ、行動を選ばないのか

内面には「どう感じているか」だけが書かれ、「どうすべきか」は一行もありません。行動の推薦・ランキング・採点は仕組みとして禁止し、実験名の混入は自動テストで検査しています。だからこそ、キャラクターが本音を隠したり、裏切りを宣言したり、自分を犠牲にしたとき、それを台本ではなく状況と内面から導かれた選択として観測できます。
