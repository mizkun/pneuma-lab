# Pneuma Lab — LLMキャラクターの心理学的ハーネス

**「毎ターン計算し直す心理状態」をコンテキスト注入すると、LLMエージェントの少人数インタラクションは人間の行動に近づくか？**

AIエージェント社会シミュレーションハッカソン Vol.2 提出作品。

## 仮説

LLMに固定のキャラ設定文を渡すだけでは、人間の集団に現れる「非合理」な現象は再現されにくい。
性格・感情・関係性・抑制を**発話のたびに決定論的に再計算**して私的コンテキストとして注入すれば、同じLLMがより人間に近い集団行動を示すはずだ。

これを、人間で再現性が確立している古典的心理学実験 —— **集団極性化（リスキーシフト / Choice Dilemma討議）** —— で検証する。

- 人間の頑健な結果: 討議後の集団の結論は、個人の事前判断の平均より**極端**になる（Myers & Lamm 1976; Isenberg 1986）
- 素のLLMの予想: 平均値への「妥協」に収束する（極性化しない）

## 3アーム比較

同一モデル・同一状況・同一の実行可能アクション・同一の出力形式。差分はキャラクターコンテキストのみ。

| アーム | システムプロンプトの内容 |
|---|---|
| `raw` | 名前のみ |
| `identity_only` | + 固定の人物像テキスト（毎ターン同一） |
| `pure_pneuma` | + **毎ターン再計算される内面**（感情PAD・表出特性・価値の葛藤・関係性・抑制・衝動） |

行動（発言・提案・賛成・沈黙）を選ぶのは常にLLM。ハーネスは行動を選ばず、推薦もしない。

## アーキテクチャ

```
決定論的ワールドコア（このリポジトリ）           LLM（Claude Opus）
┌──────────────────────────────┐      ┌──────────────────┐
│ ターン管理・実行可能アクション列挙       │ ───▶ │ 行動と言葉の選択      │
│ 心理状態計算 (B, PAD, O, Q, H, U)    │ prompt│  say / propose /     │
│ イベントログ（追記専用・全プロンプト保存）│ ◀─── │  agree / silence     │
│ 検証・コミット・状態更新              │ JSON │                      │
└──────────────────────────────┘      └──────────────────┘
```

心理モデル（`src/pneuma_lab/psyche.py`、係数はすべてシミュレーション仮説）:

- **B** 基礎特性 = Big Five + アクティブなプロジェクトによる修飾
- **PAD** 感情（pleasure / arousal / dominance）: イベントで変化し、半減期でベースラインへ減衰。否定的イベントは神経症傾向でスケール
- **O** 表出特性 = B + 自己モニタリング×役割圧 + PAD→OCEAN写像
- **関係性**: 有向（warmth / tension）。賛成・提案の上書き等のイベントから再構成
- **私的評価・抑制・衝動**: 上記の数値状態を日本語の「体験された意味」として描写（`appraisal.py`）。理論名・実験名・期待方向は一切モデルに渡さない（テストで強制）

## セットアップと実行

前提: [uv](https://docs.astral.sh/uv/), [Claude Code](https://claude.com/claude-code)（ログイン済み）。APIキーは不要 — LLM呼び出しはすべて `claude -p`（ヘッドレス）経由。

```bash
uv sync                 # 依存関係（pytestのみ。ランタイムは標準ライブラリのみ）
uv run pytest           # テストスイート（決定論的部分はモックで完結）

# 実験の実行（3アーム × 転職ジレンマ）
uv run python scripts/run_experiment.py --item career --arms raw identity_only pure_pneuma
```

結果は `output/<run_id>/` に保存される:
- `<arm>_<item>.jsonl` — 全イベントの生ログ（送信した全プロンプト・生応答を含む）
- `<arm>_<item>_summary.json` — 事前評定 / 合意値 / 事後評定
- `report.md` — アーム間のシフト量比較

## 測定

1〜10スケール（小さいほどリスク許容）で:

- **consensus_shift** = 合意値 − 事前個人平均。リスキー項目で負なら人間パターン（極性化）、0付近なら妥協パターン
- **post_shift** = 事後個人平均 − 事前個人平均（内面化）

## 結果（Claude Opus 5、各条件3レプリケーション）

人間ベンチマーク（Wallach, Kogan & Bem 1962）: 討議後の合意は事前個人平均より**極端**になり（リスキー項目ではリスク側）、事後の私的判断も同方向に動く（内面化）。「平均への妥協」仮説は人間では棄却されている。

### 手術ジレンマ（リスキー項目・床効果なし）— アームが分離した主結果

| arm | 事前評定の例 | mean consensus_shift | 極性化率 | 事前SD（個性） |
|---|---|---|---|---|
| raw | 7,7,7（全ラン全員同一） | -0.67 | 67% | **0.00** |
| identity_only | 4,7,7 | **+1.11**（人間と逆） | 0% | 1.36 |
| pure_pneuma | 4,7,7 | **-0.78**（人間方向） | **67%** | 1.30 |

- **raw はクローン集団**: 事前評定が全レプリケーション・全メンバーで同一。シフトして見えても、統合すべき意見の多様性が存在しない（集団極性化の前提を満たさない）
- **identity_only は慎重への譲歩**: 3/3回、最も慎重なメンバーの値(7)に全員が合わせた。人間の極性化と逆方向
- **pure_pneuma のみ、個性の分散を持った上で人間方向のシフト**を再現。最良ランでは事前平均6.0→合意4（-2.0）、事後私的評定も-2.33（内面化）。シフトは「朱里のさっきの指摘、こたえた」のような**説得による態度変容**として生じた — 人間の極性化の主要理論（説得的論拠説）と同じ経路

### 全項目を貫くパターン: raw は「中庸への回帰」マシン

extremization = |合意 − スケール中央5.5| − |事前平均 − 5.5|（正 = 中央から離れる = 人間的な極端化）

| arm | career | marriage | surgery |
|---|---|---|---|
| raw | -1.00 | -1.00 | -0.67 |
| identity_only | -0.33 | -0.00 | +1.11 |
| pure_pneuma | -0.56 | +0.11 | +0.56 |

- **raw の合議は9ラン中8ランでスケール中央に向かって動き、離れたランはゼロ**。人間の集団極性化（極への移動）の正反対
- identity_only の surgery +1.11 は「慎重な多数派(7,7)の初期位置に少数派(4)が3/3回屈服」した結果。多数決的収束であり、討議による論拠の統合ではない
- pure_pneuma の surgery では逆に、**リスク側の少数派(朱里4)の論拠が慎重な多数派(凛7・紫苑7)を動かした**（凛「朱里のさっきの指摘、こたえた」と自ら4を提案）— 人間の極性化の主要機構「説得的論拠」および少数者影響と同型の経路

### 副次的発見

- **面従腹背の自然発生**（pure_pneumaのみ頻出）: 「表では3に賛成したけど、私の本音は4」「話し合いでは4に乗ったけど、私の実感はやっぱり3寄り」— 公的合意と私的信念の乖離を測る `private_dissent` は raw 0.11-0.22 / pneuma 0.22-0.50
- **個性はコンテキストの産物**: ペルソナ文なし（raw）ではBig Fiveも価値観も存在せず、判断が完全に均質化する

### 限界（正直に）

- 転職ジレンマは項目文がリスク寄りに強くアンカーし床効果（事前2〜4）→ 全アーム慎重ドリフト。項目設計の感度が結果を左右する
- 結婚ジレンマ（慎重項目）は全アームで事前がほぼ7に張り付き無変化 → 極方向の弁別器として機能せず
- n=3/条件。統計的検定に足るnではなく、方向と再現性の観察に留まる
- 人間データは1960年代米国の大学生、エージェントは日本語の3キャラクター。方向比較のみ有効

## キャラクター

3人の既存キャラクター定義（`characters/*.json`）: 朱里（外向・成果志向）、凛（内向・自律・失敗恐怖）、紫苑（慎重・回避・本心を溜め込む）。Big Five / Schwartz価値観 / PADベースライン / 自己モニタリング / 回避傾向 / 開示方針を含む。

## 科学的規律

- アーム間の客観情報一致はテストで保証（`test_objective_parity_across_arms`）
- 実験名・期待方向・採点語彙がモデル向けテキストに混入しないことをテストで保証（`test_no_forbidden_terms_*`）
- 技術的失敗（パース不能等）はキャラクターの意図として記録しない
- 生ログに全プロンプト・全応答を保存し、追試可能にする
