心理学ハーネス — 心を計算し、行動は選ばない

1. 観測出来事を読む
2. 計算性格・感情・関係を更新
3. 翻訳「内面」として本人だけに渡す
4. 選択AIが行動を選ぶ
5. 記録次の計算の入力へ
実際に注入された内面（裏切られた直後の紫苑）
  • 胸の奥が重い。神経が張っていて、じっとしていられない感じがある。
  • 朱里との間には、少し張り詰めたものを感じている。

心理学の古典実験7種・デスゲーム・30日の共同生活で検証。条件間の情報はテストでバイト一致を保証。

できたこと — 個性と、社会的な質感

「一番慎重な人に全員が従う」が起きた回数
5回/5回 → 0回/5回
固定キャラ設定→内面注入で、いい子の空気読みが消え、議論が生まれる
本音の点数 → みんなの前で最初に言った点数
4→6 ／ 4→4
固定設定は本音を繕ってから議論に入る。内面があると、本音をそのまま言う

できなかったこと — 感情を与えても、意思決定は動かない

発見初版は注入文の92%が不変（介入が実質不成立）
修理発話が感情を動かす機構を追加し、予測を宣言して再実験
確認注入文の変化を確認した上で、なお動かない

同調 0%。最終回の裏切り 0%。
届かなかったのではない。届いたのに、効かなかった。

決定打 — では、何なら動くのか

「合わせてしまうことがよくある」と行動を1行書くと
同調 0% → 72%
感情の記述は効かず、行動の記述は過剰に実行される
中のモデルだけを小型に替えると
協力100% → 25%
乖離はプロンプトの外、モデルの中に住む

人間は、2つのモデルのあいだにいる。

結論 — 人間らしさの二層分解

個性・本音と建前・裏切りのドラマ——社会的な質感は、コンテキストで作れる。
つられる・損切りできない——非合理な意思決定は、モデルの訓練の中に住む。
