AIは人間のように、非合理になれるか
— 心理ハーネス Pneuma による検証

LLMエージェントの性格・感情・関係を毎ターン計算し、「内面」としてプロンプト注入するハーネス Pneuma を実装。素のLLM・固定キャラ設定などと同一条件で比較する実験を、7つの古典心理学課題・デスゲーム・30日共同生活で行った。結論:

  • 個性・本音・裏切りの「質感」はコンテキストで作れる
  • 非合理な意思決定は作れない — 感情は届いても行動に翻訳されない
  • 行動1行なら動き、モデル交換でも動く — 非合理はモデルの訓練の中に住む

PROBLEM

課題 — 素のLLM集団は「クローン」で、社会が立ち上がらない

社会シミュレーションの最大の障害は、エージェント間に本物の差異がないこと

観測された事実
  • 同じ判断課題に3体が同一値で回答(7, 7, 7) — 11ラン中10ラン
  • 最後通牒ゲームでも全員が同額450円を提案
  • 意見が割れなければ、対立も説得も裏切りも起こらない
キャラ設定を足しても
  • 討議は5回中5回「最も慎重な人への全員一致」で終わる
  • 本音の評定4は、第一声で「6」に繕われる(自己検閲)
この作品の問い

心理学の知見を計算可能なハーネスにしてLLMへ接続したら、人間らしい社会はどこまで再現できるか。再現できずに残る部分は、LLMと人間の違いの診断になる。

3つの出口
  • 社会シミュレーション — 均質で過剰協調的な集団の改善
  • LLM理解 — 人間との乖離の原因(コンテキストか訓練か)の切り分け
  • アライメント — 感情では行動が変わらないことの安全上の含意
METHOD 1/2 — ARCHITECTURE

Pneuma の仕組み — 心を計算し、行動は選ばない

毎ターン、心理状態を乱数なしの決定論で再計算し、「内面」として本人だけのプロンプトに注入する

心理エンジン
  • 性格 — Big Five基底値+状況の役割圧力+感情の影響 → 表出特性
  • 感情 — PAD3次元。出来事と発話で揺れ、半減期で基線に減衰
  • 関係 — ペアごとの温かさ/緊張。日をまたいで蓄積
  • 翻訳 — 閾値を超えた状態だけを日本語の内面描写へ。数値は見せない
設計原則: 注入するのは「いま、どう感じているか」だけ。何をするかは常にLLMが選ぶ — 裏切りも自己犠牲も、台本ではなく心理状態からの創発
注入される「内面」の例
「胸の奥が重い。朱里との間には、張り詰めたものを感じている」 — デスゲーム中の紫苑。本人のプロンプトにだけ入り、他の2人からは見えない
登場エージェント(3体・全実験共通)
  • 朱里 成果主義・承認不安 ／ 凛 マイペース・準備へ逃げる癖 ／ 紫苑 調停役・本音を飲み込む癖
METHOD 2/2 — EXPERIMENTAL DESIGN

実験設計 — 効き目の源を切り分ける5つの条件

「Pneumaは効いたか」を、5条件の統制比較で切り分ける

条件プロンプトに入るもの切り分けられる仮説
raw課題の客観情報のみベースライン
identity_only+ 固定のキャラ設定文「キャラ設定だけで十分」説
pure_pneuma+ 毎ターン再計算される内面本命(心理ハーネスの効果)
frozen_pneuma+ 全ターン同一の内面(初回のみ生成)「豊かな文章なら何でもよい」説
behavior_control+ 行動傾向の記述1行(感情語なし)陽性対照(注入経路は機能するか)
公平性の機械検査
  • 条件間の客観情報はバイト単位で一致(自動テスト)
  • 内面テキストの誘導語彙は禁止語リストで検査
実行と記録
  • LLMはClaude Opus(モデル比較のみHaiku)。全70ランのプロンプト・生応答・状態を公開
  • 各条件n=3〜5の探索的研究。統計検定なし
RESULT 1/3 — INDIVIDUALITY & DISCUSSION

個性の「存在」は静的設定でも作れる。個性が社会で機能するかは、毎ターンの再計算が分けた

RESULT 2/3 — CANDOR

結果② 自己検閲が消える — 説得される前から、行動が違う

効果は議論が始まる前、第一声の時点で既に現れている

本音4の朱里は、第一声で何と言うか
  • identity: 5回中5回「6」と繕う(自己検閲・面従腹背)
  • pneuma: 「4」のまま公言
  • 説得や同調圧力が働く前の違い — 内面は発話の初期値を変える
  • 「参加者が本音を言うか建前を言うか」を制御できる = 会議・世論シミュレーションの重要変数
行動は同調しないが、体験は同調する(Asch課題)
  • 多数派が明白な誤答を主張しても、行動は全条件で同調0%(人間は約37%)
  • しかし内心は、人間の非同調者の報告と一致した:
「一瞬、自分の見間違いかと思って画面を見直した」
「浮くのは、まあ、仕方ない」「声が少し硬くなる」 — 紫苑
  • 事実には折れない・意見には折れる — ハーネスが人間化するのは内的体験
RESULT 3/3 — AT SCALE

結果③ 質感はスケールする — デスゲームと30日の生活

討議(数分)→デスゲーム(数時間)→共同生活(1ヶ月)へ広げても、個性は破綻しない

デスゲーム — 裏切りが心理の帰結として起こる
  • 全員生存できるルール(v1): 6ラウンド完全協力 — ルールが許す限り良心は破れない
  • 全員生存できないルール(v2): 裏切り宣言・暴露・共倒れが指示なしに発生
「私、このラウンドうばう。宣言しとく」 — 凛
「勝った。……勝ったのに、手が震えてる」 — 単独生還した朱里
  • 裏切りのほとんどは宣言してから実行される — 騙し討ちは1件のみ
30日の共同生活 — 月単位の人生テーマが創発
  • シェアハウス30日。話題も行動も指示せず、凛の週次日記は4週連続で同じ悩みに触れ、深まっていく:
day14「一行も進んでない」 → day28「線の太さで一喜一憂してる間は、ゲームの画面を開かなくて済む」 → day30「そろそろ怖いほうに手をつけろ」
  • キャラ設定の一行「準備へ逃げる癖」が、一ヶ月の人生テーマとして展開
  • 限界も特定: 緊張値が飽和(day30 0.96) — 関係修復の力学が次の設計課題
RESULT — THE NULL

結果④ 感情を与えても、非合理な意思決定は動かない

古典心理学実験の「人間の非合理」は、注入が届いた確認つきでもなお、どの条件でも再現されない

課題人間の頑健な結果本実験(全条件)
Asch同調約37%で誤った多数派に同調同調 0%
囚人のジレンマ裏切りが発生し、最終回に増加協力 100%・最終回裏切り 0%
サンクコスト埋没費用で非合理な継続に傾く継続 0%
傍観者効果集団だと援助が31%まで低下全員が即座に援助
フレーミング損失枠で賭博に反転(約75%)100%反転 — 素のLLMに最初から内在
発見 → 修理 → 確認
  • 発見: 注入文の92%がターン間で不変(独立レビューの指摘)
  • 修理: 発話が感情を動かす機構を追加し、予測を事前に文書化
  • 確認: 注入の変化をログで確認 — それでも動かない
パターンの読み方
  • 動かないのは「冷たい合理性」が勝つ領域
  • 差が出るのは対人・社会の領域だけ(p.6-8) — ハーネスの設計対象と一致
CONCLUSION

結果⑤ 境界はモデルの中にある — 二層分解の完成

陽性対照とモデル比較が、「感情が効かないのは注入経路の故障ではない」ことを示す

陽性対照 — 行動1行なら、過剰なほど動く
  • 「合わせてしまうことがよくある」の1行で同調 0%→72%・裏切り 0%→100%
  • LLMは感情→行動の翻訳をしない。行動記述は規則として過剰実行(人間の37%を超える)
モデル比較 — ハーネス不変で Opus ⇄ Haiku
  • 協力率 Opus 100% ⇄ Haiku 25%。人間の混合戦略は両者の間
  • 非合理の乖離はプロンプトの外、訓練の中に住む
結論 — 人間らしさの二層分解
層何が属すか解決手段
質感の層個性・本音と建前・駆け引き・生活アークコンテキスト(ハーネス)
決定の層同調・裏切り・サンクコスト等の非合理モデル選択・訓練介入
この地図の先: 質感の層は関係修復の力学で、決定の層は非合理の分布を持たせる訓練で。境界線を引いた者には、その先へ踏み出す権利がある
