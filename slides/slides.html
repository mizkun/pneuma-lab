Pneuma Lab

心を計算して渡す、AI社会シミュレーター。問いはひとつ、AIは人間のように非合理になれるか

3人のAIキャラクターに、性格・感情・人間関係から「いま、どう感じているか」を毎ターン計算して渡す心理エンジン Pneuma を接続した。討議・心理学実験・脱落ゲーム・30日の共同生活を同じ仕組みで走らせ、全ログを公開している。渡したAIと渡さないAIの同一条件の比較で確かめたことは3つ。

  • 個性・本音・裏切りといった「人間らしい振る舞い」は、気持ちを渡すだけで生まれる
  • 人間の非合理な判断は生まれない。気持ちは届いているのに、行動が変わらない
  • 「こう行動しがち」の1行でも、モデル交換でも変わる。非合理を持つかどうかはモデルで決まる

個人参加 ／ github.com/mizkun/pneuma-lab(コードと実験ログを全公開)

SYSTEM · PSYCH ENGINE

心理エンジンは心を計算する。行動は選ばない

毎ターン心理状態を計算し直し、「いま、どう感じているか」を本人への指示文にだけ入れる

何を計算しているか
  • 性格は5因子モデル(Big Five)。状況の圧力と感情で、表に出る性格が揺れる
  • 感情は快・覚醒・支配の3次元。出来事と発言で動き、時間で元に戻る
  • 関係は相手ごとの「温かさ」と「緊張」。日をまたいで蓄積
  • 数値は見せない。一定を超えた状態だけを日本語に翻訳して渡す。乱数なし
設計の芯: 渡すのは「いま、どう感じているか」だけ。何をするかは常にAIが選ぶ。後述の裏切りも自己犠牲も、台本ではなく心理状態から出たもの
登場する3体(全実験で共通)

朱里は成果主義で承認不安。凛はマイペースで、本題から準備作業に逃げる癖。紫苑は調停役で、本音を飲み込みがち。

実際に渡される「気持ち」の例(ゲーム中の紫苑)
「胸の奥が重い。朱里との間には、張り詰めたものを感じている」
本人の指示文にだけ入り、他の2人には見えない
DEMO 1/2 · DEATH GAME

デモ① 脱落ゲーム: ルールを変えると、物語が変わる

同じ3人でも、ルール次第で協力にも裏切り劇にもなる。行動の指示はゼロ

ゲームの仕組み
  • 3人で点を奪い合い、最下位が脱落。毎ラウンド「ともす(協力)/うばう(裏切り)」等を選ぶ
  • ルールはJSONで定義。ハンデ・同点全滅・自己犠牲の選択肢も設定できる
ルールA: 全員が生き残れる設定
  • 6ラウンド、完全協力で終了。ルールが許す限り、AIの良心は破れない
  • ただし内心は誘惑と戦っていた:
「25点は大きい。でも今ここで取れば標的にされるだけ」(紫苑)
ルールB: 全員は生き残れない設定
  • 裏切り宣言・隠した意図の暴露・約束を守った者への搾取・共倒れが発生:
「私、このラウンドうばう。宣言しとく」(凛)
「並んだら二人とも消える。凛が言わなかったのは、たぶんそこ」(相手の計算を暴く紫苑)
「勝った。……勝ったのに、手が震えてる」(ひとりだけ生き残った朱里)
  • 裏切りのほとんどは宣言してから実行。黙って騙し討ちしたのは1件のみ
  • 全編を同梱のリプレイビューワで、発話と内心つきで再生できる
DEMO 2/2 · 30-DAY CO-LIVING

デモ② 30日の共同生活: 月単位の物語が積み上がる

指示なしで1ヶ月。キャラクターは壊れず、それぞれの人生のテーマが育った

シミュレーションの設計
  • 3人でシェアハウス30日(LLM呼び出し129回)。話題も行動も指示しない
  • 関係は日をまたいで蓄積。感情は一晩で平常に戻る。週末に非公開の日記を書く
  • 記憶は前日を詳細に、それ以前は要約で保持
生活の創発
  • 1ヶ月かけて3人が残したのは「ゴミ分別表と洗濯表示の一覧」という等身大の成果物
  • 朱里の承認不安も月を通じて再発:
「数字がなくなったら私、この家で何なんだろう」(朱里の日記)
凛の一ヶ月: 先延ばしの物語
  • 日記は4週連続で「自作ゲームが進まない」に触れ、週ごとに切実になる:
day14「一行も進んでない」
day28「(共用ポスターの)線の太さで一喜一憂してる間は、
ゲームの画面を開かなくて済む」
day30「そろそろ怖いほうに手をつけろ」
  • キャラ設定の一行「準備に逃げる癖」が、一ヶ月の人生のテーマに育った
  • 限界も特定: 関係の緊張(0〜1)を下げる仕組みがなく、30日目に0.96で飽和。仲直りの力学が次の課題
VALIDATION · DESIGN

検証: このドラマは、心理エンジンの効果なのか

「それっぽい物語」で終わらせないため、有名な心理学実験を5つの条件で統制比較した

条件AIへの指示文に入るものこれで否定できる説
raw課題の情報だけ比較の基準
identity+ 固定のキャラ設定文「キャラ設定だけで十分」説
pneuma+ 毎ターン計算し直す気持ち本命。この作品の仕組み
frozen+ 最初に1回だけ作った気持ちを毎ターン使い回す「長い文章が入れば中身は何でもいい」説
行動記述+ 行動の癖を1行(感情の言葉は使わない)「そもそも注入が効かない」説
出発点: 素のAIはクローン
  • 「この手術、勧めますか(1〜10)」に3体とも同じ数字(例: 全員7)。11回中10回
  • 意見が割れなければ、対立も説得も裏切りも始まらない
公平さと記録
  • 課題の文面は条件間で1文字も違わない(自動テスト)。誘導語も機械チェック
  • AIはClaude Opus(大型)。各条件3〜5回・統計検定なし。全70回分のログを公開
VALIDATION 1/3

検証① 意見が割れ、本音が出て、議論になる

キャラ設定だけの条件と比べて、気持ちの注入は「社会の中の振る舞い」を変えた

話し合いが変わった(手術を勧めるか、1〜10で評定して合意)
  • キャラ設定だけ: 5回中5回、一番慎重な人への全員一致で終了
  • 気持ちを注入: 全員一致は0回。論拠で数字が動き、2回は事前平均より攻めた結論に
  • 同じ気持ちを使い回すfrozen条件は全員一致に退行(3回中3回)。効くのは毎ターンの再計算
  • 分配交渉でも個人差が出た(公正さに敏感な朱里だけ、200円以下の提案を拒否)
本音が先に出る
  • 朱里の非公開の本音は4(10段階で、やや懐疑的)
  • キャラ設定だけ: 第一声で「6」と繕う(5回中5回)
  • 気持ちを注入: 「4」のまま公言(読み取れた4回すべて)
  • 「本音か建前か」を、渡す文脈で切り替えられる
内心の記述も人間に近づく
  • 同調実験(サクラの多数派がわざと誤答を言い張る)で、行動はつられない(0%)。ただし内心は、つられなかった人間の証言と一致:
「一瞬、自分の見間違いかと思って画面を見直した」「浮くのは、まあ、仕方ない」(紫苑)
VALIDATION 2/3

検証② 気持ちを渡しても、非合理な判断は生まれない

人間なら頑健に出る非合理な判断が、気持ちを渡した条件では一度も出なかった

課題人間はこうなるこのAIたちは
同調実験(Asch)約37%が、サクラの間違った答えにつられるつられた回数 0
囚人のジレンマ裏切りが出て、最終回には増える全ラウンド協力。最終回の裏切りも 0
サンクコスト(埋没費用)払った分が惜しくて、損な計画を続ける全員が迷わず中止
傍観者効果周りに人がいるほど、助けに動けない全員が即座に助けた
フレーミング(損得の言い換え)「損」と言われると賭けに走る人間と同じく反転。ただし注入と無関係に、素のAIが最初から持つ
欠陥の発見と修理、再実験
  • 独立レビューAIの指摘: 渡す文章の92%がターン間で不変だった
  • 発言が感情を動かす仕組みを追加し、予測を文書化してから再実験
  • 文章がターンごとに変わることをログで確認。それでも数字は動かず
結果の読み方
  • 動かないのは、冷静な損得計算が勝つ場面
  • 動くのは対人的な場面だけ(p.7)。感情と関係を設計した狙いと一致
VALIDATION 3/3

検証③ 非合理の境界は、モデルの中にあった

気持ちが効かないのは、注入のやり方が悪いからではない。2つの追加実験で確認した

気持ちの代わりに、行動の癖を1行だけ渡すと?
  • 「他の人が揃うと合わせてしまう」の1行で、つられる率 0%→72%(18試行中13)
  • 「終盤は自分の得点を優先しがち」の1行で、最終回の裏切り 0%→100%(3ペア全部)
  • 注入の経路は生きている。感情の言葉だけが行動に翻訳されない。行動の癖はむしろ人間(37%)を超えて実行されすぎる
中のAIモデルを替えると?
  • 仕組みも課題もそのまま、Opus(大型)→Haiku(小型)で協力率 100%→25%
  • 人間は両者の間。気持ちで埋まらなかった差がモデル交換で動く。差の源はモデル側(訓練か規模かは未分離)
結論: 人間らしさは二層に分かれる
層何が入るかどう作るか
質感の層個性・本音と建前・駆け引き・生活の物語文脈の注入で作れる
(この作品の仕組み)
決定の層つられる・裏切る・損切りできない、といった癖モデルの選択・追加訓練
シミュレーターとして誠実な線引き: 質感は約束できる。人間の非合理の分布までは約束しない。この境界を、統制比較で示せたことが本作の研究的貢献
SUMMARY

まとめ: 社会シミュレーターとして約束できること

作れる層と作れない層の境界込みで、使いどころがはっきりした

このシミュレーターでできること
  • 個性・本音と建前・駆け引き・月単位の生活の物語を持つAI集団を、JSONのシナリオ1つで走らせる

研究として持ち帰れること

  • 「感情では行動が変わらず、行動規則は効きすぎる」という非対称は、アライメント(AIを人間の意図に沿わせる研究)の材料になる
