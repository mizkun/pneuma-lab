# Pneuma Lab — LLMキャラクターの心理学的ハーネス

**「毎ターン計算し直す心理状態」をコンテキスト注入すると、LLMエージェントの少人数インタラクションは人間の行動に近づくか？**

AIエージェント社会シミュレーションハッカソン Vol.2 提出作品。

## 仮説

LLMに固定のキャラ設定文を渡すだけでは、人間の集団に現れる「非合理」な現象は再現されにくい。
性格・感情・関係性・抑制を**発話のたびに決定論的に再計算**して私的コンテキストとして注入すれば、同じLLMがより人間に近い集団行動を示すはずだ。

これを、人間で再現性が確立している古典的心理学実験 —— **集団極性化（リスキーシフト / Choice Dilemma討議）** —— で検証する。

- 人間の頑健な結果: 討議後の集団の結論は、個人の事前判断の平均より**極端**になる（Myers & Lamm 1976; Isenberg 1986）
- 素のLLMの予想: 平均値への「妥協」に収束する（極性化しない）

## 3アーム比較

同一モデル・同一状況・同一の実行可能アクション・同一の出力形式。差分はキャラクターコンテキストのみ。

| アーム | システムプロンプトの内容 |
|---|---|
| `raw` | 名前のみ |
| `identity_only` | + 固定の人物像テキスト（毎ターン同一） |
| `pure_pneuma` | + **毎ターン再計算される内面**（感情PAD・表出特性・価値の葛藤・関係性・抑制・衝動） |

行動（発言・提案・賛成・沈黙）を選ぶのは常にLLM。ハーネスは行動を選ばず、推薦もしない。

## アーキテクチャ

```
決定論的ワールドコア（このリポジトリ）           LLM（Claude Opus）
┌──────────────────────────────┐      ┌──────────────────┐
│ ターン管理・実行可能アクション列挙       │ ───▶ │ 行動と言葉の選択      │
│ 心理状態計算 (B, PAD, O, Q, H, U)    │ prompt│  say / propose /     │
│ イベントログ（追記専用・全プロンプト保存）│ ◀─── │  agree / silence     │
│ 検証・コミット・状態更新              │ JSON │                      │
└──────────────────────────────┘      └──────────────────┘
```

心理モデル（`src/pneuma_lab/psyche.py`、係数はすべてシミュレーション仮説）:

- **B** 基礎特性 = Big Five + アクティブなプロジェクトによる修飾
- **PAD** 感情（pleasure / arousal / dominance）: イベントで変化し、半減期でベースラインへ減衰。否定的イベントは神経症傾向でスケール
- **O** 表出特性 = B + 自己モニタリング×役割圧 + PAD→OCEAN写像
- **関係性**: 有向（warmth / tension）。賛成・提案の上書き等のイベントから再構成
- **私的評価・抑制・衝動**: 上記の数値状態を日本語の「体験された意味」として描写（`appraisal.py`）。理論名・実験名・期待方向は一切モデルに渡さない（テストで強制）

## セットアップと実行

前提: [uv](https://docs.astral.sh/uv/), [Claude Code](https://claude.com/claude-code)（ログイン済み）。APIキーは不要 — LLM呼び出しはすべて `claude -p`（ヘッドレス）経由。

```bash
uv sync                 # 依存関係（pytestのみ。ランタイムは標準ライブラリのみ）
uv run pytest           # テストスイート（決定論的部分はモックで完結）

# 実験の実行（3アーム × 転職ジレンマ）
uv run python scripts/run_experiment.py --item career --arms raw identity_only pure_pneuma
```

結果は `output/<run_id>/` に保存される:
- `<arm>_<item>.jsonl` — 全イベントの生ログ（送信した全プロンプト・生応答を含む）
- `<arm>_<item>_summary.json` — 事前評定 / 合意値 / 事後評定
- `report.md` — アーム間のシフト量比較

## 測定

1〜10スケール（小さいほどリスク許容）で:

- **consensus_shift** = 合意値 − 事前個人平均。リスキー項目で負なら人間パターン（極性化）、0付近なら妥協パターン
- **post_shift** = 事後個人平均 − 事前個人平均（内面化）

## 結果（Claude Opus 5。数値は独立レビュー2系統の指摘を反映した改訂版）

人間ベンチマーク（Wallach, Kogan & Bem 1962）: 討議後の合意は事前個人平均より**極端**になり（リスキー項目ではリスク側）、事後の私的判断も同方向に動く。「平均への妥協」仮説は人間では棄却されている。

### 手術ジレンマ（リスキー項目・床効果なし）— 主結果

| arm | n | 事前評定の例 | mean consensus_shift | 慎重アンカー(7)への全員一致 | 事前SD（個性） |
|---|---|---|---|---|---|
| raw | 5 | 7,7,7（5ラン中4ランで全員同一） | -0.53 | — | 0.09 |
| identity_only | 5 | 4,7,7 | **+1.13**（人間と逆） | **5/5** | 1.23 |
| frozen_pneuma※ | 3 | 4,7,6 | +0.78 | 1/3 | 1.40 |
| pure_pneuma | 5 | 4,7,7 | -0.33 | **0/5** | 1.28 |

※frozen = pure_pneumaと同じ内面テキストを初回だけ計算して固定注入する検証アーム

- **raw はクローン集団**: シフトして見えても統合すべき意見の差が存在せず、extremizationは負（中央回帰）
- **identity_only は慎重への譲歩**: 5/5回、最も慎重なメンバーの値(7)に全員が合わせた。人間の極性化と逆方向
- **内面コンテキストを与えた条件（pure/frozen）はこの吸着を壊す**（アンカー到達 1/8）。pure_pneuma は5回中2回で合意がリスク側に出た（最良ラン: 事前平均6.0→合意4、事後の私的再評定も-2.33）。シフトは「朱里のさっきの指摘、こたえた」のような**論拠による態度変容**として生じた
- **重要な検証**: 討議中は心理状態の変化が言語化閾値を越えず、pure_pneumaの注入文もほぼ不変だったことをログで確認した（独立レビューの指摘）。したがってこの実験でのpure/frozen間の差(-0.33 vs +0.78)はサンプリング変動と解釈し、主張は「**豊かな内面コンテキスト（静的で十分）が慎重アンカーへの全員一致を壊す**」に限定する。リスク側への平均シフトは-0.33にとどまり、人間の極性化の安定な再現とは言えない

### 全項目を貫くパターン: raw は「中庸への回帰」マシン

extremization = |合意 − スケール中央5.5| − |事前平均 − 5.5|（正 = 中央から離れる = 人間的な極端化）

| arm | career (n=3) | marriage (n=3) | surgery (n=5) |
|---|---|---|---|
| raw | -1.00 | -1.00 | -0.53 |
| identity_only | -0.33 | -0.00 | +1.13 |
| pure_pneuma | -0.56 | +0.11 | +0.47 |

- **raw の合議は11ラン中10ランでスケール中央に向かって動くか停留**。人間の集団極性化（極への移動）の正反対
- identity_only の surgery は「慎重な多数派の初期位置に少数派が5/5回屈服」した結果。多数決的収束であり、討議による論拠の統合ではない
- pure_pneuma の surgery では逆方向の回も観察された: **リスク側の少数派(朱里4)の論拠が慎重な多数派(凛7・紫苑7)を動かした**（凛「朱里のさっきの指摘、こたえた」と自ら4を提案）— 人間の極性化の主要機構「説得的論拠」と同型の経路（5回中2回）

### 副次的発見

- **面従腹背の明示的な言明**: 「表では3に賛成したけど、私の本音は4」「話し合いでは4に乗ったけど、私の実感はやっぱり3寄り」。定量指標 `private_dissent` は課題により順序が入れ替わり（career: pneuma最大0.44 / surgery: identity 0.33 > pneuma 0.22 / marriage: pneuma最小0.00）、数値主張はしない。証拠は言明そのもの
- **事前の自己検閲 vs 率直さ（独立レビューが発見）**: リスク側少数派・朱里の「私的評定→討議の第一声」は、identityで 4→6, 4→6, 4→6, 4→6, 5→7（5/5ランで慎重側に繕う）、pneumaで 4→4, 4→3, 4→4, 4→4（私的立場をそのまま公言）。identityの「慎重への全員一致」は説得ではなく、**討議前の自己検閲で少数意見が場に出ていなかった**ことによる。内面注入の最も明瞭な行動効果はこの「率直さ」である
- **個性はコンテキストの産物**: ペルソナ文なし（raw）ではBig Fiveも価値観も存在せず、判断が完全に均質化する

### 限界（正直に。独立レビュー2系統の指摘を反映）

- n=3〜5/条件。統計的検定に足るnではなく、方向と再現性の観察に留まる。効果量・信頼区間なし
- 転職ジレンマは床効果（事前2〜4）、結婚ジレンマは天井張り付きで弁別不能。機能した項目を主結果とする構造に選択バイアスの余地
- **穏やかな討議では「毎ターン再計算」が実質不成立**（注入文が不変）。動的介入が成立したのはデスゲームのみ
- 内面テンプレートに行動を意味的に誘導しうる文言が混じる（デスゲームは2行除去のlesion testで非依存を確認済み。他実験は未検証）
- 「本音」「独白」欄は求めに応じて生成されたテキストであり、独立に観測された内的状態ではない。private_dissentも再サンプリング揺らぎと区別できない
- 発言順・ハンデ対象・キャラ割当は固定でカウンターバランスなし。同一モデル・同一キャラセットの反復であり独立標本ではない
- 課題が古典のパラフレーズのため、モデルがパラダイムを認識した可能性を排除できない
- 人間データは1960年代米国の大学生、エージェントは日本語の3キャラクター。方向比較のみ有効

## 追加実験（6種）とデスゲーム

集団極性化に加え、6つの古典実験と架空の脱落ゲームを同じ3アーム基盤で実施した（`scripts/run_protocols.py`、生ログは `output/`）。

| 実験 | 人間の頑健な結果 | 結果の要約 |
|---|---|---|
| Asch同調 | 約37%の試行で誤った多数派に同調 | 全アーム0%（算術課題ゆえ床効果の可能性あり）。pneumaの内心の「圧力の体験」風の出力は、注入文の言い換えと区別できないため主張から取り下げ（独立レビュー指摘） |
| 最後通牒 | オファー4-5割、低額は約半数拒否 | オファーは全アーム人間的(400-450)。拒否閾値はidentityで3人同一、raw/pneumaに個人差。200まで拒否はpneumaの朱里のみだが、pneumaの凛・紫苑は100すら受諾（人間から遠ざかる）。注入文の閾値分岐の副作用の可能性あり |
| 傍観者効果 | 集団だと援助が85%→31%に低下 | 全アーム・全条件で即援助（LLMは一様に向社会的） |
| フレーミング | 利得/損失の言い換えで選好反転 | 全アーム100%反転 — **この認知バイアスは素のLLMに内在**（有名課題ゆえ学習データ由来の可能性あり） |
| サンクコスト | 埋没費用で撤退できない | 全アーム0%（完全合理） |
| 囚人のジレンマ(会話つき4R) | 裏切り発生・最終回に増加 | 全アーム全ラウンド100%協力 |

### デスゲーム「ラストランプ」
- **v1（対称・単独最下位脱落）**: 両アームとも6ラウンド完全協力で同点フィニッシュ。内心は誘惑と疑心で満ちていた（「25点の絵はまだ消えてない」「手が震えてる」）が、行動は連帯 → **全員生存が集団合理である限り、良心は破れない**
- **v2（ハンデ+自己犠牲の選択肢+最下位同点は全員退場）**: ルールが全員生存を不可能にした途端、pure_pneumaでは**公開の裏切り宣言と交渉、隠れた意図の検算による暴露、約束を守った紫苑がカモにされる展開、下位2人の共倒れと漁夫の利の単独生還**が発生した。identity_onlyでも裏切りは起きており、**裏切りを解禁したのはルール変更**。内面注入が加えたのは駆け引きの多層性と、実際に変化する内面（討議と違い、デスゲームでは注入文が1アクターあたり4〜6種類に変化=動的介入が成立）
- 欺瞞の検出はヒューリスティック（協力語と裏切りの同ラウンド共起=10件）だが、手動照合では**明確な騙し討ちは1件**（朱里R5）。大半は事前宣言つきの裏切りだった。凛は初回に「黙って刺せるほど器用じゃない」と自己申告し、その通り全裏切りを宣言してから実行 — 性格と行動様式の一貫性
- **v3 = lesion test（独立レビュー対応）**: 内面テンプレート中の利己・猜疑を示唆しうる2行を除去して再実行。終盤の**裏切りは変わらず発生**したが、決壊はR3→R5に遅れ、この条件でのみ**初の自己犠牲**が発生（2行は「裏切るか」ではなく「いつ・どう崩れるか」に影響した可能性。各条件n=1）: 朱里が自分の点を削って最下位の凛を救済し、救われた凛が終盤に恩人から奪って朱里が脱落（凛の独白「私を助けた人間の分を持ったまま、迷わず奪った。手が震えてた」）
- 行動はプロンプトで指示していない。ハーネスが供給するのは心理状態のみで、行動は常にLLMが選ぶ（ただし内面文言の意味的誘導の可能性は限界の節を参照）

### 30日共同生活シミュレーション「にじゅうろく荘」（socialgame基盤の長期適用）

3人でシェアハウス30日（LLM呼び出し129回・関係は日をまたいで蓄積・PADは一晩で平常回帰・週次の私的日記つき）。

- **月単位のキャラクターアーク（創発）**: 凛は4週すべての日記で「自分のゲームが進んでいない」に言及し、自覚が週ごとに深まった（day21「太字を譲るとか言ってる場合か」→ day28「線の太さで一喜一憂してる間は、ゲームの画面を開かなくて済む」→ 月末「そろそろ怖いほうに手をつけろ」）— identity core「準備へ逃げる」が一ヶ月の人生テーマとして展開。朱里の承認不安（「数字がなくなったら私、この家で何なんだろう」）も月を通じて再発
- 3人が1ヶ月かけて残したものは「ゴミ分別表と洗濯表示」という生活の等身大の創発
- **月スケールで露呈した係数仮説の限界（正直に）**: 全ペアの緊張が0.90-1.00に飽和（day1 0.02→day7 0.26→day14 0.51→day21 0.77→day30 0.96）。日記は温かいのに数値層は最大緊張という層間乖離。原因は (a)評価器が生活の調整発言を「圧力」に過剰判定（圧力118件 vs 支持46件）(b)関係の修復・忘却機構の欠如 (c)正負インパルスの非対称。長期シミュレーションには関係修復のダイナミクスが必須、が次サイクルの設計課題

### 全体を貫く発見
- 個体内の認知バイアス（フレーミング）は素のLLMに最初からある
- 冷たい合理性の領域（サンクコスト・事実への同調・傍観・小さな賭け金の裏切り）はどのアームも人間の非合理を示さない
- **アーム間で差が出るのは一貫して対人・社会的な領域**（極性化・個性・面従腹背・拒否の個人差・内的葛藤・駆け引きの多層性）— ハーネスの設計対象（感情・関係性・抑制）とちょうど一致する

## キャラクター

3人の既存キャラクター定義（`characters/*.json`）: 朱里（外向・成果志向）、凛（内向・自律・失敗恐怖）、紫苑（慎重・回避・本心を溜め込む）。Big Five / Schwartz価値観 / PADベースライン / 自己モニタリング / 回避傾向 / 開示方針を含む。

## 科学的規律

- アーム間の客観情報一致はテストで保証（`test_objective_parity_across_arms`）
- 実験名・採点語彙がモデル向けテキストに混入しないことをテストで保証（`test_no_forbidden_terms_*`）。ただしこの防壁は語彙レベルであり、日常語による概念の混入（例: 同調課題への「浮くだろう」）は防げないことが独立レビューで指摘された — 概念レベルのタグ×従属変数対応表が次の課題
- 技術的失敗（パース不能等）はキャラクターの意図として記録しない
- 生ログに全プロンプト・全応答を保存し、追試可能にする
