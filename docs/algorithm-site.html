PNEUMA — HOW IT WORKS

心を計算し、
行動は選ばない。

Pneuma（プネウマ）は、LLMキャラクターに「いまこの瞬間の内面」を持たせる仕組みだ。性格・感情・人間関係を発話のたびに計算し直し、日本語の「心の中」としてキャラクター本人だけに手渡す。何をするかは、AIが自分で決める。

01
観測
これまでに起きた出来事（発言・裏切り・賛成）を読む
02
計算
性格・感情・関係の数値状態を決定論で更新
03
翻訳
数値を日本語の「内面」に変換し、本人だけに渡す
04
選択
LLMが行動と言葉を選ぶ — ここだけは計算しない
05
記録
選択は出来事として記録され、次の計算の入力になる
↺ 発言のたびに、このループが回る

LAYERS

計算している、心の4つの層

PERSONALITY

性格 — 変わらない土台

ビッグファイブ5因子と価値観10種。生まれつきの数値は不変だが、進行中の目標（「キャンペーンを成功させたい」）が一時的に性格を押し上げる。B = G + プロジェクト修飾

AFFECT

感情 — 揺れて、戻る

快−不快・覚醒・主導感の3軸（PADモデル）。出来事で跳ね、時間とともに半減期でその人の平常へ戻る。神経症傾向が強い人ほど、嫌な出来事で大きく揺れる。

EXPRESSION

表出 — 場で変わる顔

「いま表に出る性格」。土台の性格に、場の圧力×自己モニタリング（人の目を気にする度合い）と感情の影響を足して算出。同じ人でも場面で違う顔になる。

RELATIONSHIP

関係 — 向きのある温度

相手ごとの「親しみ」と「緊張」。賛成されれば温まり、提案を潰されたり裏切られたりすれば張り詰める。私→あなた と あなた→私 は別の値。

計算はすべて乱数を使わない決定論。同じ出来事の列からは、必ず同じ心理状態が導かれ、あとから完全に追跡できる。

TRY IT

出来事を起こすと、心が動く

実際のエンジンの簡易移植です。キャラクターを選んで、出来事のボタンを押してみてください。数値が動き、閾値を越えた瞬間に「内面」の文章が変わります。この文章が、そのままLLMに手渡されるものの原型です。

PROMPT

内面は、プロンプトの最後の一層になる

キャラクターへの入力は3層。実験ではこの層を出し分けて、素のLLM（raw）・固定キャラ設定（identity）・Pneuma（+内面）を比較した。

LAYER 1 — 客観情報（全条件で共通）

状況の説明、これまでの会話、いま選べる行動、出力形式。ここに主観は一切入らない。

LAYER 2 — 人物像（固定テキスト）

「場を明るくして人を前へ出したい。数字や成果がないと自分に価値がないように感じる」——変わらないアイデンティティ。

LAYER 3 — いまの内面（毎ターン計算）

「胸の奥が重い。朱里との間には張り詰めたものを感じている。反対があっても言い出しにくい」——上の実験機で見た、あの文章。

raw = Layer 1のみ identity_only = 1 + 2 pure_pneuma = 1 + 2 + 3

BOUNDARY

設計上の一線 — なぜ行動を選ばないのか

内面には「どう感じているか」だけが書かれ、「どうすべきか」は一行もない。行動の推薦・ランキング・採点は仕組みとして禁止し、実験名の混入は自動テストで検査している。だからこそ、実験でキャラクターが本音を隠したり、裏切りを宣言したり、自分を犠牲にしたりしたとき、それを台本ではなく、状況と内面から導かれた選択として観測できる。

この誠実さには限界もある（内面の文言が行動を意味的に誘導しうる等）。検証の全記録は実験レポートの「正直な限界」に記載。
