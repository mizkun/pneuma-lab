AIは人間のように、非合理になれるか

AIに「いまの気持ち」を毎ターン計算して渡す仕組み、Pneuma の検証記録

AIのキャラクターに、性格・感情・人間関係から「いま、どう感じているか」を毎ターン計算して渡す仕組みを作った。名前は Pneuma。これを渡したAIと渡さないAIを同じ条件で比べる実験を、心理学の有名な実験7つと、脱落ありの心理戦ゲーム、30日間の共同生活でやってみた。わかったことは3つ。

  • 個性や本音や裏切りといった「人間らしい振る舞い」は、気持ちを渡すだけで生まれる
  • でも、人間の非合理な判断は生まれない。気持ちは届いているのに、行動が変わらない
  • 「こう行動しがち」と1行書けば行動は変わるし、AIモデルを替えても変わる。非合理を持つかどうかは、モデル自身で決まっている

PROBLEM

素のAIを3体並べると、全員が同じことを言う

AIエージェントで社会を模擬しようとすると、まずここでつまずく

実際にやってみると
  • 「この手術、患者に勧めますか。おすすめ度を1〜10で」と3体に聞くと、3体とも同じ数字を返す(例: 全員が7)。11回試して10回そうだった
  • 1000円の分け方を提案させても、3体とも450円。ぴったり同じ
  • 意見が割れないから、対立も説得も裏切りも始まらない
キャラ設定のプロンプトを足すと?
  • 口調は変わる。でも話し合いになると、一番慎重な人の意見に全員が乗って終わる。5回やって5回とも
  • 本音は10段階の4なのに、みんなの前では「6」と言う。建前で議論が始まる
この作品の問い

性格・感情・関係という心理学の道具立てを、計算できる形でAIにつないだら、人間らしい社会はどこまで再現できるのか。再現できずに残った部分は、AIと人間の違いがどこにあるかを教えてくれる。

うまくいくと何が嬉しいか
  • 社会シミュレーション: 「全員同じで、過剰に協力的」という集団の問題を直せる
  • AIの理解: 人間と違う原因が、渡す文脈にあるのか、モデルの訓練にあるのかを切り分けられる
  • アライメント(AIを人間の意図に沿わせる研究): 感情では行動が変わらない、という性質そのものが安全設計の材料になる
METHOD 1/2

Pneuma は心を計算する。行動は選ばない

毎ターン、心理状態を計算し直して、「いま、どう感じているか」を本人への指示文にだけ入れる

何を計算しているか
  • 性格は、心理学で標準的な5因子モデル(Big Five)で持つ。状況の圧力や感情しだいで、表に出る性格が少し揺れる
  • 感情は3次元(快・覚醒・支配)。出来事や発言で動き、時間が経つと元に戻る
  • 人間関係は相手ごとに「温かさ」と「緊張」の値で持ち、日をまたいで積み重なる
  • 数値はそのまま見せない。一定を超えた状態だけを日本語に翻訳して渡す。乱数は使わない
設計の芯: 渡すのは「いま、どう感じているか」だけ。何をするかは常にAI自身が選ぶ。だから後で出てくる裏切りも自己犠牲も、台本ではなく心理状態から自然に出てきたもの
登場する3体(全実験で共通)

朱里は成果主義で、認められないと不安になる。凛はマイペースで、本題から準備作業に逃げる癖がある。紫苑は調停役で、本音を飲み込みがち。

実際に渡される「気持ち」の例
「胸の奥が重い。朱里との間には、張り詰めたものを感じている」
心理戦ゲームの最中に紫苑へ渡されたもの。本人の指示文にだけ入り、他の2人には見えない
METHOD 2/2

実験のやり方

「効いた」と言うために、何が効いたのかを切り分ける5つの条件を、すべての実験に用意した

条件AIへの指示文に入るものこれで否定できる説
raw課題の情報だけ比較の基準
identity+ 固定のキャラ設定文「キャラ設定だけで十分」説
pneuma+ 毎ターン計算し直す気持ち本命。この作品の仕組み
frozen+ 最初に1回だけ作った気持ちを毎ターン使い回す「長い文章が入れば中身は何でもいい」説
行動記述+ 行動の癖を1行(感情の言葉は使わない)「そもそも注入が効かない」説
公平さの担保
  • 課題の点数やルールの文面は、条件間で1文字も違わないことを自動テストで確認している
  • 渡す気持ちの文章に、答えを誘導する言葉が紛れていないかも機械チェック
実行と記録
  • AIはClaude Opus(大型)。モデル比較の実験だけ、小型のHaikuも使った
  • 各条件3〜5回の探索的な実験で、統計的な検定はしていない。指示文と生の応答は全70回分をそのまま公開
RESULT 1/5

結果① 意見が割れて、議論が生まれた

「個性がある」だけならキャラ設定でも作れる。個性が社会の中で働くかどうかは、毎ターンの再計算で分かれた

回答が人によって変わるようになった
  • 課題は1000円の分配。取り分を提案し、相手に拒否されると2人とも0円になる
  • 提案額は、素のAIだと3体とも450円。気持ちを渡すと420円と450円に割れた
  • 拒否の癖も割れた。公正さに敏感な設定の朱里だけが、200円以下の提案を突っぱねるようになった
話し合いが変わった
  • 課題は「成功率の低い手術を勧めるか」。各自が1〜10で評定してから、3人で合意を作る
  • キャラ設定だけだと、一番慎重な人に全員が合わせて終わる(右の図)
  • 気持ちを渡すと、論拠で数字が動く。5回中2回は事前の平均より攻めた結論になった。人間の集団で知られる「話し合うと意見が極端になる」現象と同じ向き
「一番慎重な人への全員一致」で話し合いが終わった回数
同じ気持ちの文章を、更新せずに使い回したら?
  • キャラ設定と同じ結果に戻った。3回試して3回とも全員一致
  • 効いているのは文章の豊かさではなく、毎ターン計算し直すことだとわかる
RESULT 2/5

結果② 本音を繕う癖が消えた

効果が出るのは、説得や同調圧力がかかる前。第一声の時点ですでに違う

本音が4の朱里は、第一声で何と言うか
  • 手術の課題で、朱里がこっそり付けた本音の評定は4(10段階で、やや懐疑的)
  • キャラ設定だけだと、みんなの前では「6」と言う。5回中5回、繕ってから議論に入った
  • 気持ちを渡すと「4」のまま言う。読み取れた4回、すべてそうだった
  • つまり「本音を言うか、建前を言うか」を、渡す文脈で切り替えられる
行動はつられないが、内心は人間に近づく
  • 同調実験(Asch)は、サクラの多数派がわざと間違った答えを言い張る実験。人間は約37%がつられて誤答する
  • AIは一度もつられなかった(どの条件でも0%)。ただ、内心のログには、つられなかった人間の証言とそっくりのことが書かれていた:
「一瞬、自分の見間違いかと思って画面を見直した」
「浮くのは、まあ、仕方ない」「声が少し硬くなる」(紫苑)
  • 事実の問いには折れず、意見の問いには折れる。この仕組みが変えたのは内面の描写の質だった
RESULT 3/5

結果③ 長い時間でも、キャラクターは壊れない

数分の話し合いから、数時間の心理戦ゲーム、30日の共同生活まで、時間を延ばして観測した

脱落ありの心理戦ゲーム
  • 3人で点を奪い合い、最下位が脱落する。行動の指示は一切していない
  • 全員が生き残れるルールだと、6ラウンド全部協力で終わった。ルールが許す限り、AIの良心は破れない
  • 全員は生き残れないルールに変えた途端、裏切り宣言、隠した意図の暴露、共倒れまで一気に出てきた
「私、このラウンドうばう。宣言しとく」(凛)
「勝った。……勝ったのに、手が震えてる」(ひとりだけ生き残った朱里)
  • 裏切りはほとんど宣言してから実行された。黙って騙し討ちしたのは1件だけ
  • この裏切りはルールに追い込まれた末の選択でもある。合理を捨ててまで裏切るか、は次のページで
30日の共同生活
  • 3人でシェアハウス30日。話題も行動も指示せず、週末だけ誰にも見せない日記を書かせた
  • 凛の日記は、4週連続で「自作ゲームが進まない」に触れて、だんだん切実になっていく:
day14「一行も進んでない」
day28「(共用ポスターの)線の太さで一喜一憂してる間は、
ゲームの画面を開かなくて済む」
day30「そろそろ怖いほうに手をつけろ」
  • キャラ設定に書いた一行「準備に逃げる癖」が、一ヶ月がかりの人生のテーマに育った
  • 限界も見つかった。関係の緊張(0〜1の値)を下げる仕組みがなく、30日目には0.96まで張り詰めたまま。仲直りの力学が次の宿題
RESULT 4/5

結果④ 気持ちを渡しても、非合理な判断は生まれない

人間なら頑健に出る非合理な判断が、気持ちを渡した条件では一度も出なかった

課題人間はこうなるこのAIたちは
同調実験(Asch)約37%が、サクラの間違った答えにつられるつられた回数 0
囚人のジレンマ裏切りが出るし、最終回には増える全ラウンド協力。最終回の裏切りも 0
サンクコスト(埋没費用)払った分が惜しくて、損な計画を続ける全員が迷わず中止
傍観者効果周りに人がいるほど、助けに動けない全員が即座に助けた
フレーミング(損得の言い換え)「損」と言われると賭けに走る人間と同じく反転。ただし気持ちの注入とは無関係で、素のAIが最初から持っていた
途中で欠陥が見つかり、直してから再実験した
  • 文脈を知らないレビューAIが指摘: 渡している文章の92%が、ターンをまたいでも変わっていなかった
  • 発言が感情を動かす仕組みを足し、「今度は変わるはず」という予測を先に文書にしてから再実験
  • 文章がターンごとに変わることをログで確かめた。それでも、上の数字は動かなかった
結果の読み方
  • 動かなかったのは、冷静な損得計算が勝つ場面ばかり
  • 動いたのは対人的な場面だけ(p.6-8)。感情と関係を設計したこの仕組みの狙いと、ちょうど重なる
RESULT 5/5 + CONCLUSION

結果⑤ 非合理の境界は、モデルの中にあった

気持ちが効かないのは、注入のやり方が悪いからではない。2つの追加実験で確かめた

気持ちの代わりに、行動の癖を1行だけ渡したら?
  • 「他の人が揃うと合わせてしまう」の1行で、つられる率が0%から72%に跳ねた(18試行中13)
  • 「終盤は自分の得点を優先しがち」の1行で、最終回の裏切りが0%から100%に(3ペア全部)
  • 注入の経路は生きている。感情の言葉だけが行動に翻訳されない。しかも行動の癖は人間(37%)を超えて律儀に実行されすぎる
中のAIモデルを替えたら?
  • 仕組みも課題もそのまま、大型のOpusを小型のHaikuに替えたら、協力率は100%から25%へ
  • 人間はこの2つの間にいる。気持ちの注入で埋まらなかった人間との差が、モデル交換では動いた。差の源はモデル側にある(訓練のせいか規模のせいかは、まだ分けられていない)
結論: 人間らしさは二層に分かれる
層何が入るかどう作るか
質感の層個性・本音と建前・駆け引き・生活の物語文脈の注入で作れる
(この作品の仕組み)
決定の層つられる・裏切る・損切りできない、といった癖モデルの選択・追加訓練
この先: 質感の層には仲直りの力学(p.8の宿題)を足す。決定の層は、人間の非合理の分布を持つモデルを作る側の仕事になる。境界が引けたので、次にやることがはっきりした
