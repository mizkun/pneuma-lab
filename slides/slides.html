1

問題: 素のLLMは「いい子」すぎて、社会にならない

ペルソナなしのLLM3体に同じ判断課題を個別に答えさせると——

課題3体の事前評定（3レプリケーション）
転職ジレンマ3, 3, 3 / 3, 3, 3 / 3, 3, 3
手術ジレンマ7, 7, 7 / 7, 7, 7 / 7, 7, 7

全ラン・全員が同一値。個性が存在しない。

個性のないエージェント集団では:

  • 意見の対立が生まれない → 統合・説得・譲歩も起こらない
  • 裏切り・本音と建前・自己犠牲などの人間的な現象が原理的に出ない
  • 社会シミュレーションの土台が崩れる

キャラ設定文を足せば解決？ —— それを実験で確かめた。

2

Pneuma: 発話のたびに心理状態を計算し直すハーネス

設計思想: ハーネスは行動を選ばない

  • 心理状態の計算は決定論、選択は常にLLM
  • 推奨・ランキング・期待方向の注入を禁止（テストで強制）
  • ファインチューニング不要・モデル非依存

比較する3アーム

raw名前のみ
identity_only+ 固定のキャラ設定文（毎ターン同一）
pure_pneuma+ 毎ターン再計算される内面

客観情報（状況・履歴・選択肢・出力形式）は3アームでバイト一致（テスト保証）

3

検証: 人間で再現性が確立した実験を、そのままAIに

集団極性化（リスキーシフト）

Stoner (1961) → Wallach, Kogan & Bem (1962)、以後数百件の追試で確立された、社会心理学で最も頑健な現象のひとつ。

  1. 各自が選択ジレンマに私的に回答（1〜10、小さいほどリスク許容）
  2. 3人で討議し、全員一致の結論を出す
  3. 再び私的に回答

人間の頑健な結果

  • 合意は事前個人平均より極端になる（リスキー項目ではリスク側）
  • 「平均への妥協」仮説は棄却されている
  • 事後の私的判断も同方向に動き、数週間持続（内面化）

AIエージェント集団は、
人間と同じように動くか？

手術ジレンマ・事前評定の3人のばらつき（母標準偏差、3レプリケーション平均）

意見の多様性は、集団現象が起こるための前提条件 —— rawはこの時点で脱落する。

7

考察: 何が生まれ、何がまだ足りないか

生まれたもの

  • 個性の分散（判断の多様性）
  • 説得による態度変容（人間の極性化の主要因「説得的論拠」と同じ経路）
  • 面従腹背・条件付き譲歩（「書面がないなら数字は無効」）
  • リスキー項目での人間方向シフト（2/3ラン）

まだ足りないもの（正直に）

  • 転職ジレンマは項目文の床効果で全アーム慎重ドリフト → 項目設計に感度が依存
  • 結婚ジレンマ（慎重項目）は全員が事前7に張り付き弁別不能
  • n=3/条件。方向と再現性の観察に留まる

次サイクル仮説: 情動の伝染（他者の発話が聞き手のPADを直接動かす経路）を1機構だけ追加し、未使用シナリオで転移検証する。

8

これから: 検証済みの心理の上に、ドラマを立てる

目標は「AIエージェント同士のデスゲームが、エンタメとして面白くなる」こと。

  • 裏切り・自己犠牲・本音と建前が「演出」ではなく心理状態の帰結として起こる世界
  • そのためには、まず心理ハーネスが人間的現象を再現できることの検証が先 —— 本作はその第一歩
  • ハーネスは行動を選ばないので、同じ基盤の上にどんなシナリオ（協力・対立・取引・極限状況）でも載る

再現性

全62テスト / 全ラン27本の生ログ（送信プロンプト・生応答込み）/ 心理計算は乱数なしの決定論 / LLM呼び出しはClaude Code CLI経由でAPIキー不要。リポジトリの README.md から一括再実行可能。
