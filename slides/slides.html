AIは人間のように、非合理になれるか

AIに「いまの気持ち」を毎ターン計算して渡す仕組み Pneuma の検証

性格・感情・人間関係から「いま、どう感じているか」を毎ターン計算し、AIに渡す仕組み Pneuma を作った。渡したAIと渡さないAIを同一条件で比較する実験を、有名な心理学実験7つ・脱落ありの心理戦ゲーム・30日間の共同生活で実施。結論は3つ。

  • 個性・本音・裏切りといった「人間らしい振る舞い」は、気持ちを渡すだけで生まれる
  • 人間の非合理な判断は生まれない。気持ちは届いているのに、行動が変わらない
  • 「こう行動しがち」の1行でも、モデル交換でも変わる。非合理を持つかどうかはモデルで決まる

Pneuma Lab ／ 個人参加 ／ github.com/mizkun/pneuma-lab(コードと実験ログを全公開)

PROBLEM

素のAIを3体並べると、全員が同じことを言う

AIで社会を模擬する最大の障害は、エージェントの間に本物の差異がないこと

観測された事実
  • 「この手術、患者に勧めますか。おすすめ度を1〜10で」に、3体とも同じ数字を回答(例: 全員7)。11回中10回
  • 1000円の分け方の提案も、3体とも同額の450円
  • 意見が割れなければ、対立も説得も裏切りも始まらない
キャラ設定を足しても
  • 口調は変わるが、話し合いは5回中5回「一番慎重な人への全員一致」で終わる
  • 本音の評定4(10段階)は、第一声で「6」に繕われる
この作品の問い

性格・感情・関係という心理学の知見を、計算できる形でAIにつないだら、人間らしい社会はどこまで再現できるか。再現できずに残る部分は、AIと人間の違いの診断になる。

この検証の使い道
  • 社会シミュレーション: 「全員同じ・過剰に協力的」な集団の改善
  • AIの理解: 人間との差の原因が、渡す文脈かモデルの訓練かを切り分け
  • アライメント(AIを人間の意図に沿わせる研究): 「感情では行動が変わらない」性質が安全設計の材料に
METHOD 1/2

Pneuma は心を計算する。行動は選ばない

毎ターン心理状態を計算し直し、「いま、どう感じているか」を本人への指示文にだけ入れる

何を計算しているか
  • 性格は5因子モデル(Big Five)。状況の圧力と感情で、表に出る性格が揺れる
  • 感情は快・覚醒・支配の3次元。出来事と発言で動き、時間で元に戻る
  • 関係は相手ごとの「温かさ」と「緊張」。日をまたいで蓄積
  • 数値は見せない。一定を超えた状態だけを日本語に翻訳して渡す。乱数なし
設計の芯: 渡すのは「いま、どう感じているか」だけ。何をするかは常にAIが選ぶ。後述の裏切りも自己犠牲も、台本ではなく心理状態から出たもの
登場する3体(全実験で共通)

朱里は成果主義で承認不安。凛はマイペースで、本題から準備作業に逃げる癖。紫苑は調停役で、本音を飲み込みがち。

実際に渡される「気持ち」の例(心理戦ゲーム中の紫苑)
「胸の奥が重い。朱里との間には、張り詰めたものを感じている」
本人の指示文にだけ入り、他の2人には見えない
METHOD 2/2

実験のやり方

何が効いたのかを切り分ける5つの条件を、すべての実験に用意した

条件AIへの指示文に入るものこれで否定できる説
raw課題の情報だけ比較の基準
identity+ 固定のキャラ設定文「キャラ設定だけで十分」説
pneuma+ 毎ターン計算し直す気持ち本命。この作品の仕組み
frozen+ 最初に1回だけ作った気持ちを毎ターン使い回す「長い文章が入れば中身は何でもいい」説
行動記述+ 行動の癖を1行(感情の言葉は使わない)「そもそも注入が効かない」説
公平さの担保
  • 課題の点数・ルールの文面は、条件間で1文字も違わない(自動テストで検査)
  • 渡す気持ちの文章に、答えを誘導する言葉がないことも機械チェック
実行と記録
  • AIはClaude Opus(大型)。モデル比較のみ小型のHaiku
  • 各条件3〜5回の探索的実験。統計検定なし。指示文と生応答は全70回分を公開
RESULT 1/5

結果① 意見が割れて、議論が生まれた

個性の「存在」はキャラ設定でも作れる。社会の中で働くかは、毎ターンの再計算で分かれた

回答に個人差が出た
  • 課題は1000円の分配。提案を拒否されると2人とも0円
  • 提案額は、素のAIだと3体とも450円。気持ちを渡すと420円と450円に分かれた
  • 公正さに敏感な設定の朱里だけが、200円以下の提案を拒否
話し合いが変わった
  • 課題は「成功率の低い手術を勧めるか」。各自1〜10で評定し、3人で合意を作る
  • キャラ設定だけだと、一番慎重な人に全員が合わせて終わる(右図)
  • 気持ちを渡すと論拠で数字が動き、5回中2回は事前平均より攻めた結論に。人間の「話し合うと意見が極端になる」現象と同方向
「一番慎重な人への全員一致」で話し合いが終わった回数
同じ気持ちの文章を、更新せずに使い回すと?
  • キャラ設定と同じ結果に戻る。3回中3回、全員一致
  • 効いているのは文章の豊かさではなく、毎ターンの再計算
RESULT 2/5

結果② 本音を繕う癖が消えた

効果が出るのは説得や同調圧力の前。第一声の時点ですでに違う

本音が4の朱里は、第一声で何と言うか
  • 手術の課題で、朱里が非公開で付けた本音の評定は4(10段階で、やや懐疑的)
  • キャラ設定だけだと、みんなの前では「6」と言う。5回中5回
  • 気持ちを渡すと「4」のまま言う。読み取れた4回すべて
  • 「本音か建前か」を、渡す文脈で切り替えられる
行動はつられないが、内心は人間に近づく
  • 同調実験(Asch)は、サクラの多数派がわざと間違った答えを言い張る実験。人間は約37%がつられて誤答する
  • AIはどの条件でも0%。ただし内心のログには、つられなかった人間の証言と同じ内容が並ぶ:
「一瞬、自分の見間違いかと思って画面を見直した」
「浮くのは、まあ、仕方ない」「声が少し硬くなる」(紫苑)
  • 事実には折れず、意見には折れる。変わったのは内面の描写の質
RESULT 3/5

結果③ 長い時間でも、キャラクターは壊れない

数分の話し合いから、数時間の心理戦ゲーム、30日の共同生活まで時間を延ばして観測した

脱落ありの心理戦ゲーム
  • 3人で点を奪い合い、最下位が脱落。行動は一切指示しない
  • 全員が生き残れるルールでは、6ラウンド完全協力。ルールが許す限り良心は破れない
  • 全員は生き残れないルールに変えると、裏切り宣言・意図の暴露・共倒れが発生
「私、このラウンドうばう。宣言しとく」(凛)
「勝った。……勝ったのに、手が震えてる」(ひとりだけ生き残った朱里)
  • 裏切りのほとんどは宣言してから実行。騙し討ちは1件のみ
  • この裏切りはルールに追い込まれた選択。合理を捨てる裏切りは次ページで
30日の共同生活
  • 3人でシェアハウス30日。話題も行動も指示せず、週末に非公開の日記だけ書かせた
  • 凛の日記は4週連続で「自作ゲームが進まない」に触れ、週ごとに切実になる:
day14「一行も進んでない」
day28「(共用ポスターの)線の太さで一喜一憂してる間は、
ゲームの画面を開かなくて済む」
day30「そろそろ怖いほうに手をつけろ」
  • キャラ設定の一行「準備に逃げる癖」が、一ヶ月の人生のテーマに育った
  • 限界も特定: 関係の緊張(0〜1)を下げる仕組みがなく、30日目に0.96で飽和。仲直りの力学が次の課題
RESULT 4/5

結果④ 気持ちを渡しても、非合理な判断は生まれない

人間なら頑健に出る非合理な判断が、気持ちを渡した条件では一度も出なかった

課題人間はこうなるこのAIたちは
同調実験(Asch)約37%が、サクラの間違った答えにつられるつられた回数 0
囚人のジレンマ裏切りが出て、最終回には増える全ラウンド協力。最終回の裏切りも 0
サンクコスト(埋没費用)払った分が惜しくて、損な計画を続ける全員が迷わず中止
傍観者効果周りに人がいるほど、助けに動けない全員が即座に助けた
フレーミング(損得の言い換え)「損」と言われると賭けに走る人間と同じく反転。ただし注入と無関係に、素のAIが最初から持つ
欠陥の発見と修理、再実験
  • 独立レビューAIの指摘: 渡す文章の92%がターン間で不変だった
  • 発言が感情を動かす仕組みを追加し、予測を文書化してから再実験
  • 文章がターンごとに変わることをログで確認。それでも数字は動かず
結果の読み方
  • 動かないのは、冷静な損得計算が勝つ場面
  • 動くのは対人的な場面だけ(p.6-8)。感情と関係を設計した狙いと一致
RESULT 5/5 + CONCLUSION

結果⑤ 非合理の境界は、モデルの中にあった

気持ちが効かないのは、注入のやり方が悪いからではない。2つの追加実験で確認した

気持ちの代わりに、行動の癖を1行だけ渡すと?
  • 「他の人が揃うと合わせてしまう」の1行で、つられる率 0%→72%(18試行中13)
  • 「終盤は自分の得点を優先しがち」の1行で、最終回の裏切り 0%→100%(3ペア全部)
  • 注入の経路は生きている。感情の言葉だけが行動に翻訳されない。行動の癖はむしろ人間(37%)を超えて実行されすぎる
中のAIモデルを替えると?
  • 仕組みも課題もそのまま、Opus(大型)→Haiku(小型)で協力率 100%→25%
  • 人間は両者の間。気持ちで埋まらなかった差がモデル交換で動く。差の源はモデル側(訓練か規模かは未分離)
結論: 人間らしさは二層に分かれる
層何が入るかどう作るか
質感の層個性・本音と建前・駆け引き・生活の物語文脈の注入で作れる
(この作品の仕組み)
決定の層つられる・裏切る・損切りできない、といった癖モデルの選択・追加訓練
この先: 質感の層には仲直りの力学(p.8)を足す。決定の層は、人間の非合理の分布を持つモデル側の課題。境界が引けたことで、次の一手が明確になった
