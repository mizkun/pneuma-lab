Pneuma Lab

あらゆる社会シミュレーションで、AIを人間らしくする「心理ハーネス」

「◯◯をシミュレーションしてみた」という作品ではなく、その土台になる道具を作りました。素のAIは、3体並べると全員が同じことを言います。そこで性格・感情・関係を毎ターン計算して「いま、どう感じているか」をAIに渡す心理エンジンを作り、渡した場合と渡さない場合を同じ課題で比べました。

  • 気持ちを渡すと、裏切りも本音も駆け引きも出てきます
  • それでも、多数派につられるような人間の非合理だけは出ません
  • 「つい合わせてしまう」と1行書くか、モデルを替えると出ます。非合理はモデルの中にありました

個人参加 ／ github.com/mizkun/pneuma-lab(コードと実験ログを全公開)

システム

3人のAIが、討議もゲームも共同生活もする

シナリオを与えると、心理エンジン付きのAIキャラクターが社会を演じ、全過程がログに残ります

構成

  • 心理学実験 7種(同調・分配交渉など)
  • 脱落ありの対戦ゲーム

システム ／ 心理エンジン

心理エンジンは心を計算する。行動は選ばない

毎ターン心理状態を計算し直し、「いま、どう感じているか」を本人への指示文にだけ入れます

何を計算しているか
  • 性格は5因子モデル(Big Five)で持ち、状況と感情で表に出る分が揺れる
  • 感情は快・覚醒・支配(場を握れている感覚)の3次元。出来事で動き、時間で戻る
  • 関係は相手ごとに温かさと緊張を持ち、日をまたいで積み上がる
  • 数値は見せない。閾値を超えた分だけ日本語にして渡す。乱数は使わない
中身の式(抜粋)

表に出る性格 O = clamp( B + m×R + 0.25×g(E) )

Bは元の性格、Rは状況の圧力、mは空気を読む度合い、g(E)は感情の影響

感情の揺れ E ← E + I×(0.5 + N)

Iは出来事の衝撃(表引き)、Nは神経症傾向。嫌な出来事ほど強く響く

感情の減衰 E ← base + (E − base)×0.5Δt/T

半減期Tで平常(base)へ戻る。係数と衝撃表は事前に固定し、実験ごとに調整しない

登場する3体(全実験で共通)
  • 朱里は成果主義で、認められないと不安になる
  • 凛はマイペースで、本題から準備に逃げる癖
  • 紫苑は調停役で、本音を飲み込みがち
実際に渡される「気持ち」の例(ゲーム中の紫苑)
「胸の奥が重い。朱里との間には、張り詰めたものを感じている」
本人の指示文にだけ入り、他の2人には見えません
渡すのは気持ちだけで、何をするかは常にAIが選びます。裏切りも自己犠牲も、台本ではありません
デモ 1/2

デモ① 脱落ゲーム。ルールを変えると、物語が変わる

同じ3人でも、ルール次第で協力にも裏切り劇にもなります。行動の指示はしていません

ゲームの仕組み
  • 3人で点を奪い合い、最下位が脱落
  • 毎ラウンド「ともす(協力)/うばう(裏切り)」等を選ぶ
  • ルールはJSONで定義。ハンデ・同点全滅・自己犠牲も設定可
ルールA(全員が生き残れる)
  • 6ラウンド全て協力で終わる。全員が生き残れるうちは、裏切りが出ない
  • ただし内心は誘惑と戦っていた
「25点は大きい。でも今ここで取れば標的にされるだけ」(紫苑)
ルールB(全員は生き残れない)
  • ハンデを付け、同点なら並んだ全員が脱落するルールに変更した
  • すると、裏切り宣言・意図の暴露・搾取・共倒れが一気に出てくる
「私、このラウンドうばう。宣言しとく」(凛)
「並んだら二人とも消える。凛が言わなかったのは、たぶんそこ」(相手の計算を暴く紫苑)
「勝った。……勝ったのに、手が震えてる」(ひとりだけ生き残った朱里)
  • 裏切りはほぼ宣言してから実行。騙し討ちは1件のみ
  • 全編を同梱ビューワでリプレイ再生できる
デモ 2/2

デモ② 30日の共同生活。月単位の物語が積み上がる

指示なしで1ヶ月。キャラクターは壊れず、それぞれの人生のテーマが育ちました

シミュレーションの設計
  • 3人でシェアハウス30日(LLM呼び出し129回)
  • 話題も行動も指示しない。週末に非公開の日記
  • 関係は日をまたいで蓄積。感情は一晩で回復
  • 記憶は前日を詳細に、それ以前は要約で保持
生活の創発
  • 1ヶ月の成果物は「ゴミ分別表と洗濯表示の一覧」だった
  • 朱里の承認不安も、月を通じて顔を出す
「数字がなくなったら私、この家で何なんだろう」(朱里の日記)
凛の、先延ばしの一ヶ月
  • 日記は4週連続で「自作ゲームが進まない」に触れ、週ごとに切実になっていく
day14「一行も進んでない」
day28「(共用ポスターの)線の太さで一喜一憂してる間は、
ゲームの画面を開かなくて済む」
day30「そろそろ怖いほうに手をつけろ」
  • キャラ設定の一行「準備に逃げる癖」が、一ヶ月のテーマに育った
  • 限界も見つかった。3人のどのペアも関係の緊張(0〜1)が下がらず、30日目に0.96で飽和。仲直りの力学が次の課題
検証 ／ 設計

このドラマは、心理エンジンの効果なのか

「それっぽい物語」で終わらせないため、有名な心理学実験を5つの条件で統制比較しました

条件AIへの指示文に入るものこれで否定できる説
raw(素のまま)課題の情報だけ比較の基準
identity(キャラ設定)+ 固定のキャラ設定文「キャラ設定だけで十分」説
pneuma(本作)+ 毎ターン計算し直す気持ち本命。この作品の仕組み
frozen(凍結)+ 最初に1回だけ作った気持ちを使い回す「長い文章なら中身は何でもいい」説
behavior(行動記述)+ 行動の癖を1行(感情の言葉なし)「注入自体が効かない」説。これで変われば経路は生きている
そもそも、素のAIはクローン
  • 「この手術、勧めますか(1〜10)」に3体とも同じ数字を返す(たとえば全員7)。実験11回中10回
  • 意見が割れなければ、対立も裏切りも始まらない
公平さと記録
  • 課題の文面が条件間で1文字も違わないことを、自動テストで確認。誘導語も機械チェックする
  • AIはClaude Opus(大型)。各条件3〜5回で統計検定はなし。ログは全70回分を公開している
検証 1/3

検証① 意見が割れ、本音が出て、議論になる

キャラ設定だけの条件と比べて、気持ちの注入は「社会の中の振る舞い」を変えました

話し合いが変わった(手術を勧めるか、1〜10で評定して合意)
  • キャラ設定だけだと、5回中5回、一番慎重な人への全員一致で終わる
  • 気持ちを注入すると全員一致は0回になり、論拠で数字が動く
  • frozen(気持ちを使い回し)は全員一致に退行(3回中3回)。効くのは毎ターンの再計算
  • 分配交渉(1000円)でも個人差が出た。公正さに敏感な朱里だけが、200円以下の提案を拒否
本音が先に出る
  • 討議の前に、全員が非公開の事前評定を出す(全条件共通の手順)
  • 朱里の事前評定、つまり本音は4(10段階)
  • キャラ設定だけだと、第一声は「6」(5回中5回)
  • 気持ちを注入すると「4」のまま公言した(数字を明言した4回すべて)
  • 本音か建前かを、渡す文脈で切り替えられる
内心の記述も人間に近づく
  • 同調実験(多数派がわざと誤答を言い張る)で、行動はつられない(0%)
  • 内心は、つられなかった人間の証言とそっくりだった
「一瞬、自分の見間違いかと思って画面を見直した」(紫苑)
検証 2/3

検証② 気持ちを渡しても、非合理な判断は生まれない

人間なら頑健に出る非合理な判断が、気持ちを渡した条件では一度も出ませんでした

課題人間はこうなるこのAIたちは
同調実験(Asch)約37%が、サクラの間違った答えにつられるつられた回数 0
囚人のジレンマ裏切りが出て、最終回には増える全ラウンド協力。最終回の裏切りも 0
サンクコスト(埋没費用)払った分が惜しくて、損な計画を続ける全員が迷わず中止
傍観者効果周りに人がいるほど、助けに動けない全員が即座に助けた
フレーミング(損得の言い換え)「損」と言われると賭けに走る人間と同じく反転。ただし注入と無関係に、素のAIが最初から持つ
欠陥の発見と修理、再実験
  • 文脈を知らない別のAIに査読させると、渡す文章の92%がターン間で不変だと発覚
  • 発言が感情を動かす仕組みを足し、予測を文書化してから再実験した
  • 文章がターンごとに変わることをログで確かめた。それでも数字は動かなかった
結果の読み方
  • 動かないのは、冷静な損得計算が勝つ場面
  • 動くのは対人的な場面だけ(p.7)。効く/効かないの境界は一貫している
検証 3/3

検証③ 非合理の境界は、モデルの中にあった

気持ちが効かないのは、注入のやり方が悪いからではありません。2つの追加実験で確認しました

行動の癖を1行だけ渡すと?
  • 「他の人が揃うと合わせてしまう」→ つられる率 0%→72%(18試行中13)
  • 「終盤は自分の得点を優先しがち」→ 最終回の裏切り 0%→100%(3ペア全部)
  • 注入の経路は生きている。感情の言葉だけが行動に翻訳されない
  • 行動の癖は人間(37%)を超えて実行されすぎる
中のAIモデルを替えると?
  • 仕組みも課題も変えず、Opus(大型)をHaiku(小型)に替えると協力率は 100%→25%
  • 人間は両者の間にいる。差の源はモデル側(訓練か規模かは未分離)
結論、人間らしさは二層に分かれる
層何が入るかどう作るか
質感の層個性・本音と建前・駆け引き・生活の物語文脈の注入で作れる
(この作品の仕組み)
決定の層つられる・裏切る・損切りできない、といった癖モデルの選択・追加訓練
約束できるのは質感までで、非合理の分布までは約束しません。この線引きを統制比較で示せたことが、本作の研究的な貢献だと考えています
まとめ

社会シミュレーターとして、約束できること

作れる層と作れない層の境界込みで、使いどころがはっきりしました

このシミュレーターでできること
  • 個性・本音と建前・駆け引き・生活の物語を持つAI集団を、JSON1つで走らせられる
  • 「全員同じで過剰に協力的」というAI集団の共通問題への処方箋になる
研究として持ち帰れること
  • 人間との差の原因を「渡す文脈か、モデルか」で切り分ける方法論
  • 「感情は効かず、行動規則は効きすぎる」という非対称は、アライメント(AIを人間の意図に沿わせる研究)の材料になる

  • 脱落ゲームのリプレイビューワ
  • 仕組みの解説サイト(たとえ話⇄数式の5段階)
  • 約3分のデモ動画
この先は、仲直りの力学を足して長期シミュレーションを安定させるつもりです。人間の非合理の分布を持つモデルと組めば、「人間の分布を持つ人工集団」に近づきます
